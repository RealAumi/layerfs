Cause: vitest.config.ts sets isolate: false. The restore hook is a module-level
afterEach in __tests__/utils.ts, which server-hmr, server-no-hmr, server-runtime
and server-source-maps all import. A worker evaluates utils.ts once, so the hook
attaches only to the first of those files that worker runs. When server-source-maps
runs after another of them in the same worker, its edit is never restored.
