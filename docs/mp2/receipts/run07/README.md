## Evidence and source identity

`results.jsonl` keeps every Commit/unmount reply, wall ns, umount trace and
successful post-unmount thread inventory. `commands.jsonl` keeps full argv,
output, exit and wall ns for all harness operations. Each Join failure keeps:

- `processes.json`: every sandbox process's comm, command, status, cwd, root,
  all open fd links and fdinfo, every thread's stack/wchan/syscall/mountinfo,
  and waiting values for the exact `/dev/fuse` connection IDs from fdinfo.
- `namespaces.json`: one full mountinfo per namespace observed through every
  host task's `/proc/.../ns/mnt`, collected by an owned read-only host-PID
  observer. Errors/races are retained; this cannot enumerate a namespace with
  no visible task. No host mount, process or descriptor was modified.
- `umount.trace`: exact `umount2` flags and result, including split/resumed
  strace lines. Every selected normal detach uses flags **0**, never lazy/force.
- `daemon.log`, `server.log`: original runtime logs.

FUSE mount or sandbox file/cwd/root holder; no remaining Git/GC/fsmonitor
process. This proves idle-receive Join failure after known namespace detach.
It does not identify an internal kernel reference or establish why OrbStack
failed to wake/disconnect these readers. The retained v6.1 `dev.c` reference
is explanatory upstream source, not a matched OrbStack kernel build.
